# Лабораторна робота № 4 — «Робота із файлами»

## Мета роботи
Ознайомлення з базовими потоками вводу-виводу (`InputStream`, `OutputStream`, `File`, `FileWriter`, `FileReader`, `BufferedReader`) для збереження, читання та пошуку даних у текстових файлах.

## Основний функціонал (`FileManager`)
* **Генерація даних:** Створення колекції (`ArrayList<String>`) випадкових символьно-цифрових рядків.
* **Збереження у файл (`1.txt`):** Запис елементів колекції у текстовий файл по одному на рядок.
* **Читання з файлу:** Зчитування вмісту за допомогою `BufferedReader`, виведення у консоль та підрахунок загальної кількості стрічок.
* **Пошук та запис результатів (`2.txt`):** Зчитування з консолі спеціального рядка, розділеного комами, пошук відповідників у файлі `1.txt` та запис номерів знайдених рядків у новий файл `2.txt`.
